# Patches

The PHONI and Augmented PHONI changes the freeze binaries were built with, as `git format-patch`
output against their upstream base commits (`revisions.json`). They are the commits of the upstream
pull requests koeppl/phoni#4 and drnatebrown/aug_phoni#2, kept here in case those are never merged.
Each patch is under its upstream project's license: both PHONI and Augmented PHONI are MIT
(copyright 2020 Massimiliano Rossi). Apply one with `git am` on a checkout of its base commit.
