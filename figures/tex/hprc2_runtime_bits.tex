% Runtime bit widths of the HPRC2 Orbit indexes, from their ORBITIDX headers
% (ms index-plan, binary ms-dca2a4e, 2026-10-05), and of the ms-bakery chr22-h100
% indexes (chr22 of 100 haplotypes; frozen hprc2 build 1d580b6), from the
% preambles of their MSIX v4 / TMSX v8 files.  MB = rows x bits / 8 / 1e6,
% the packed rows only (each Orbit table adds about 100 bytes of preamble and 8
% of slack).  "HPRC2+, 472 haps" is human472 and "10 haps from HPRC2" is p10
% (its first 10 assemblies: CHM13, GRCh38 and both haplotypes of CN1, YAO,
% KSA001 and HG002); both use the FMD text (every contig and its reverse
% complement, each ending in $, N kept), and p10's sep row the %-separated
% Movi text.  "100 chr22s" is the ms-bakery chr22-h100 cell.
% Widths are those of indexes built from Orbit idxfmt 51823f3 on: LF's phi off
% column has width 0 (queries read phi points only at run heads, where the
% offset is 0).  Files built earlier, including the rewrapped HPRC2 indexes,
% carry 1 bit there (phi samples route) or 11 (chr22-h100, LF-walk route).
