\paragraph{Query reads.}
We queried four sets of real sequencing reads against the HPRCv2 index.
For the three human sets, we drew a reproducible random sample of the deposited run with \texttt{seqkit sample} (fixed seeds) and took a fixed prefix of the sample totaling about 60\,Mbp; the metagenomic set is described below. We kept only reads consisting entirely of A, C, G and T after uppercasing.
Reads containing any other character were dropped whole rather than split, so every tool receives identical, unmodified reads; this removed fewer than 0.3\% of bases from any set.
Table~\ref{tab:reads} summarizes the resulting workloads.
For every workload, matching statistics from every tool were checked position by position against reference values derived from \texttt{ropebwt3 mem -l1} SMEMs over the same pangenome.

\textbf{Short reads.}
Illumina HiSeq 2500 paired-end WGS reads ($2\times125$\,bp) from the CHM1 hydatidiform mole cell line (SRA run SRR3099549, BioProject PRJNA176729).
CHM1 is not among the HPRCv2 haplotypes, so the reads come from a genome absent from the index.
Mates were sampled together and treated as independent queries.

\textbf{PacBio.}
PacBio Sequel~II reads from HPRC sample HG00099 (SRR26545347, BioProject PRJNA701308).
% verify: ENA labels the file "subreads"; read lengths (6.9 to 36.8 kbp, median 20.1 kbp) are typical of HiFi, but HiFi processing is not established from the metadata.
Both HG00099 haplotypes are part of HPRCv2, so this set represents querying reads from a genome that is in the index.

\textbf{Nanopore (human).}
Oxford Nanopore reads from NA12878 (GM12878), the complete flow cell FAB42260 from release~6 of the Nanopore WGS Consortium~\cite{jain2018nanopore} (R9.4 chemistry; verify).
NA12878 is not among the HPRCv2 haplotypes.
The sample spans reads from 10\,bp to 72\,kbp (median 4.3\,kbp, N50 10.3\,kbp), and, unlike the other sets, no reads were removed by the A/C/G/T filter.
% Optional, if the modern ONT set is reported:
% We also report a modern Nanopore set: a 0.8\% random subsample (samtools view --subsample 0.008, seed 20261003) of the quality-passing R10.4.1 reads from HG002 released by Oxford Nanopore in December 2023 (gm24385\_2023.12). HG002 is in HPRCv2. Its read lengths range from 404\,bp to 417\,kbp (median 3.4\,kbp, N50 91.7\,kbp).

\textbf{Guccione et al.\ skin metagenome.}
Illumina NovaSeq~6000 paired-end shotgun reads (up to $2\times151$\,bp) from an atopic dermatitis skin swab, run ERR14066769 of the host-depletion study PRJEB83637 by Guccione et al.~\cite{guccione2025incomplete} (verify that PRJEB83637 is this paper's deposit).
These reads were deposited after host-read filtering, so most should be microbial and should match the human pangenome only in short stretches.
This set therefore represents the screening use case, where most queries are not from the indexed genomes.
Among the PRJEB83637 skin runs with at least 60\,Mbp of usable sequence, ERR14066769 was chosen for having the highest fraction of sampled reads whose longest exact HPRCv2 match was at least 50\,bp (a measure of residual human sequence).
We took the largest prefix of whole read pairs in deposited order totaling at most 60\,Mbp; reads are 45 to 151\,bp as deposited (median 151\,bp).
